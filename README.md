# Coffee Shop ☕

A simple Java application for a coffee shop ordering system, where customers customize their coffee order and get the total price instantly using OOP.

## Features
- ☕ Choose from multiple coffee types (Black, Latte, Cappuccino)
- 📏 Select a size (Small, Medium, Large)
- 🥛 Choose milk type (Regular, Oat, Almond)
- ➕ Add an extra shot
- 🍰 Choose a dessert (muffin, brownie)
- 💵 Automatic price calculation based on all selected options

## How It Works
The program asks the user to enter their coffee preferences (type, size, milk, extra shot, and sweetness), then a `Coffee` class calculates the total price based on all selected options using `switch` and `if` statements.

## Technologies
- Java (OOP - Classes & Objects)
- `Scanner` class for user input
